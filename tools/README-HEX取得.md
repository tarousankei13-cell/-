# 注文コード(HEX)の取り出しかた

公式のモバイルオーダーで組んだ注文を、**送信する直前に止めて**
中身を16進で取り出します。**注文も支払いも発生しません。**

取り出した16進は

* BOTの注文パネル「注文コード(HEX)を貼る」に貼る → そのまま注文できる
* `/debug learn code:...` に貼る → セットの組み立て方をBOTが覚える

の2通りに使えます。

---

## スマホの人（おすすめ）— ブックマークレット

**入れるものはありません。**

### 用意（最初の1回）

1. `hex_catcher_bookmarklet.txt` の中身を**全部**コピー
2. ブラウザで適当なページをブックマークに追加
3. そのブックマークを編集し、**URLを消して貼り付け**、名前を `hex` にする

### 使うとき

1. 公式のモバイルオーダーを開いて、いつもどおり商品を組む
2. **支払いに進む前に**、アドレス欄に `hex` と打ってブックマークを選ぶ
3. 「準備できました」と出る
4. 支払いへ進む → 16進の箱が出る → コピー

⚠️ 箱を閉じたあと画面にエラーが出ます。**それが正常**です。
   送信を止めているので、マクドナルドには何も届いていません。

⚠️ 箱が出ないときは、下の「ユーザースクリプト」を使ってください。
   ブックマークレットはページが読み込まれたあとに割り込むので、
   アプリの作りによっては間に合わないことがあります。

---

## 確実にしたい人 — ユーザースクリプト

`hex_catcher.user.js` を入れます。ページが読み込まれる**前**から
待ち構えるので、こちらのほうが確実です。

| 端末 | 入れ方 |
|---|---|
| Android | **Firefox** を入れ、アドオンから **Tampermonkey** を追加 |
| iPhone | App Store の **Userscripts**（無料）を入れ、Safari で有効にする |
| パソコン | Chrome / Edge / Firefox に **Tampermonkey** を追加 |

そのうえで `hex_catcher.user.js` の中身を貼り付けて保存します。

---

## どの商品を取ると役に立つか

`/debug bridges` で「分かっていない枠」が見られます。
そこに出ている商品を組んで取ると、BOTが注文できる範囲が広がります。

いま効くのは**ハッピーセット系**です。
サイドもドリンクもおもちゃも、**全部ちゃんと選んでから**取り出してください。
選んだ状態がそのまま記録されます。

---

## 困ったとき

| 症状 | 見るところ |
|---|---|
| 箱が出ない | ログインできているか／アドレスが `mobileorder.mcdonalds.co.jp` か |
| 本当に注文されていないか不安 | 公式アプリの注文履歴。何も増えていないはずです |
| 16進が短すぎる | 商品を選び切れていない可能性。組み直してもう一度 |
