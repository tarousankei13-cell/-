# 注文番号ページ（単体版）

マクドナルド注文BOTとは**別の場所**で動かすためのものです。
BOT から注文番号を受け取り、店頭で見せるページを出すだけ。

## ここに置かれないもの

- 利用者の残高・元帳・注文履歴
- マクドナルド / Kyash の認証情報
- Discord のトークン

仮にこのサーバーを覗かれても、漏れるのは
**注文番号・店舗名・受取方法・時刻**だけです。

## 置き方

1. このZIPを展開して、ホスティングサービスに置く
2. 環境変数を設定する

| 環境変数 | 必須 | 内容 |
|---|---|---|
| `PUSH_SECRET` | ✅ | BOT と共有する合い言葉。長めの文字列にしてください |
| `PORT` | | 待ち受けるポート（多くのサービスが自動で入れます） |
| `HOST` | | 待ち受けるアドレス（未指定なら `0.0.0.0`） |
| `DATA_DIR` | | 保存先（既定 `./data`） |
| `EXPIRE_HOURS` | | 何時間で消すか（既定 12）。0で消さない |

3. 起動する（エントリーポイントは `main.py`）
4. BOT 側で設定する

```
/config web remote api_url:https://あなたのURL/api/receipts secret:同じ合い言葉
```

`/config web test` でつながるか確認できます。

## 動作確認

```
https://あなたのURL/healthz
→ {"ok": true, "ready": true}
```

`ready` が `false` なら `PUSH_SECRET` が入っていません。

## 保存先が消えても大丈夫です

再起動でファイルが消える環境でも、失われるのは**その時点の注文番号ページ**だけです。
注文番号は Discord の控えにも入っているので、受け取りには困りません。
残高などの大事なデータは、こちらには一切ありません。

## 合い言葉はそのまま流れません

BOT は合い言葉の**指紋（SHA-256）**を送ります。
日本語の合い言葉でも使えます（HTTPヘッダはASCIIしか運べないため、
そのまま送ると壊れます）。
