## 3行まとめ

- 利用者は **Kyash送金リンク**で残高をチャージし、**hex**を貼って注文する
- 管理者が設定した**負担率**の分だけ支払いが割り引かれる（ロール別に設定可）
- 注文後、**注文番号を実値に差し替えたレシート画像**が DM に届き、実績チャンネルへ匿名で記録される

## 実装AIへ

`docs/06-実装指示書.md` の **§0「絶対に守るルール」** から読むこと。
金銭を扱うため、**二重課金・二重受取・残高の不整合**が最大のリスクである。
