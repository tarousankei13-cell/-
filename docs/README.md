### 注文を組み立てるときの注意

`docs/09` の実物の注文コードと**バイト単位で一致**させること。
構造が1段違うだけ、フラグが1バイト多いだけで相手は受け付けない。

- セットの選択枠には中間ノードが入ることがある（カタログに載っていない）
- 既定のままの具材は送らない。変えたものだけ送る
- field 1 のフラグは「子を持つ中間ノードだけ」に付く

`tests/test_set_order.py` が実物との一致を検証している。

## 3行まとめ

- 利用者は **Kyash送金リンク**で残高をチャージし、**hex**を貼って注文する
- 管理者が設定した**負担率**の分だけ支払いが割り引かれる（ロール別に設定可）
- 注文後、**注文番号を実値に差し替えたレシート画像**が DM に届き、実績チャンネルへ匿名で記録される
